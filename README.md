🌍 GlobeTrotter

A full-stack travel planning and itinerary management application for creating, organizing, budgeting, and sharing trips.

GlobeTrotter is a modern travel planning platform that helps users discover destinations, build detailed itineraries, manage trip budgets, save favorite destinations, and share trips publicly.

The project includes a Python/FastAPI backend, React + Vite frontend, SQLite database, JWT authentication, itinerary management, activity discovery, budget tracking, and an admin analytics dashboard.
